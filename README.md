
# 📊 Superstore Orders Dashboard
An interactive data visualization project that analyzes sales performance, profit, discounts, and customer segments using a Superstore dataset.


This dashboard provides key business insights into:

* Profit performance
* Order quantities
* Discount impact
* Sales trends over time
* Market and segment analysis

It is designed to help stakeholders quickly understand business performance and identify opportunities for growth.

## 📌 Features

* **KPI Cards**

  * 💰 Total Profit: 105.48K
  * 📦 Total Quantity: 11K
  * 🏷️ Total Discount: 407.20

* **Time-Series Analysis**

  * Yearly, quarterly, monthly, and daily sales trends

* **Segment Analysis**

  * Profit distribution across:

    * Consumer
    * Corporate
    * (Optional: Home Office if included in dataset)

* **Category Breakdown**

  * Office Supplies
  * Technology
  * Furniture
